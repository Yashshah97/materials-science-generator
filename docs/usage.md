# Usage

```python
import materials_science_generator
```

Each module is self-contained; see docstrings for the API:

- `materials_science_generator.config` — Module to store configurable constants and default values
- `materials_science_generator.data_generator` — Main module for generating synthetic data
- `materials_science_generator.lattice_properties` — Module containing functions for simulating crystal lattice properties
- `materials_science_generator.alloy_properties` — Module containing functions for simulating alloy properties
- `materials_science_generator.tests_test_data_generator` — Test module for the data generator
- `materials_science_generator.docs_gen_docs` — Module to generate documentation for the project
